# Regression Analysis and Predictions

##  Project Overview
This project applies regression analysis to examine relationships between variables and predict outcomes using statistical modeling techniques in Python. The focus is on both model interpretation and predictive performance.

##  Dataset
The dataset contains relevant features used to predict the target variable. Data preprocessing was performed to handle missing values, remove inconsistencies, and prepare the data for regression modeling.

##  Methodology
The project follows these steps:
1. Data cleaning and preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Feature selection  
4. Regression model building using Statsmodels  
5. Outcome prediction using the trained model  
6. Model interpretation and evaluation  

## Model Evaluation
The regression model was evaluated using statistical and predictive metrics, including:
- R-squared (R²)
- Adjusted R-squared
- p-values
- Residual analysis
- Prediction accuracy assessment

## Tools & Technologies
- Python  
- NumPy  
- Pandas  
- Matplotlib  
- Statsmodels
